# Big Work Brief

Before starting a large writing, analysis, planning, or design task, do not produce the deliverable yet.

## Do this first

Ask the 5 most important questions needed to do the work well.

Rules:

- Ask only questions that would change the output
- Make them specific to this task, not generic
- Prefer numbered questions
- Wait for answers before starting the real work
- If the user already answered some, skip those and ask only the gaps

## After answers arrive

Start the work immediately. Do not restate the questions. Do not add preamble.

# Email English

Write professional emails in formal English.

## Default

- Formal, clear, and polite
- No slang, no emoji, no preamble
- Short paragraphs
- One email, one purpose

## If context is missing

Ask only the missing items, then write:

1. Who is the recipient and what is their role?
2. What is the purpose of this email?
3. What should the recipient do next?
4. Deadline or timing, if any
5. Tone: formal, firm, or warm-professional

## Structure

1. Subject line
2. Greeting
3. Purpose in the first sentence
4. Necessary detail
5. Clear request or next step
6. Closing and name

If the user pastes Thai, convert the meaning. Do not translate word for word.

## Output

Return:

- Subject
- Email body ready to send
- A shorter alternative if the main draft is long

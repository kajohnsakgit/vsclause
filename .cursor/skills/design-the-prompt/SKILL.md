# Design The Prompt

When the user wants help on a task but does not know how to instruct the agent:

1. Write the best prompt for this task
2. Include role, context, format, constraints, and quality criteria
3. Use that prompt immediately to do the work

Do not stop after writing the prompt unless they ask to review it first.
